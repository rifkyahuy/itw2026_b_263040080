Belajar Simple Selectors

Kenali cara memilih elemen HTML dengan selector dasar, lalu lihat contoh CSS-nya.

Apa itu selector?

Selector adalah bagian dari CSS yang menentukan elemen HTML mana yang akan diberi gaya.

selector {
  properti: nilai;
}

1. Universal selector

Selector * memilih semua elemen pada halaman. Contoh ini mengatur perhitungan ukuran elemen.

* {
  box-sizing: border-box;
}

2. Type selector

Selector berdasarkan nama tag, seperti p, memilih semua elemen dengan tag tersebut.

p {
  line-height: 1.6;
}

3. Class selector

Selector class diawali titik. Class bisa digunakan pada banyak elemen. Perhatikan teks penting ini.

.catatan {
  background: #fef3c7;
  color: #854d0e;
}

4. ID selector

Selector ID diawali tanda pagar dan ditujukan untuk satu elemen unik. Judul besar di bagian atas memakai id="judul-utama".

#judul-utama {
  font-size: 3rem;
}

5. Grouping selector

Beberapa selector dapat digabung dengan koma agar memakai aturan yang sama. Contoh ini berlaku untuk semua h2 dan p.

h2, p {
  font-family: Arial, sans-serif;
}

Ringkasan

* semua elemen · p tag · .catatan class · #judul-utama ID

Gunakan koma untuk mengelompokkan selector, misalnya h2, p.
